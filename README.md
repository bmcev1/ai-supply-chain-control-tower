# AI Supply Chain Control Tower Dashboard

This project is a Tableau dashboard that uses synthetic supply chain data to simulate an AI-enabled control tower for logistics and procurement analysis.

The dashboard analyzes supplier risk, shipment delays, carrier performance, inventory exposure, estimated delay cost, and recommended operational actions. It was inspired by emerging enterprise supply chain AI workflows involving decision intelligence, ERP automation, digital twins, TMS automation, and logistics inbox automation.

## Tools Used

- Tableau
- Excel
- Data visualization
- Supply chain analytics
- Synthetic data modeling

## Key Features

- Supplier risk ranking
- AI platform impact comparison
- Carrier delay performance analysis
- Inventory pressure heatmap
- Action queue for high-priority shipments
- Interactive filters for supplier, carrier, AI platform, and priority tier

## Dataset Note

The dataset used in this project is synthetic and was created for portfolio and learning purposes. It does not contain confidential company data.

## Project Goal

The goal of this project is to demonstrate how Tableau can be used to analyze operational supply chain risk and present insights in a clear, business-friendly dashboard.
